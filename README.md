# Call Bridge

A Flutter application for playing Call Bridge.

## Getting started

### Prerequisites

- [Flutter](https://docs.flutter.dev/get-started/install)
- A connected device or emulator

### Run the app

```bash
flutter pub get
flutter run
```

## Build

```bash
flutter build apk
```

## Development

Run the analyzer and tests with:

```bash
flutter analyze
flutter test
```
